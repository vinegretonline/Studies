# Практическая работа № 1

| Файл | Задание |
|------|---------|
| Task1.java | Массив задан инициализацией, сумма и среднее арифметическое (for) |
| Task2.java | Ввод массива с клавиатуры, сумма (do while, while), максимум и минимум |
| Task3.java | Вывод аргументов командной строки (for) |
| Task4.java | Первые 10 чисел гармонического ряда, форматированный вывод |
| Task5.java | Метод класса для вычисления факториала (for) |

Для Task3 аргументы задаются в Run -> Edit Configurations -> Program arguments.
